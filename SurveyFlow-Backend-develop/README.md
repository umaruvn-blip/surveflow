# Survey Flow Backend

Survey Flow Backend is the API service for the Survey Flow platform.

The project focuses on helping users create, publish, discover, and participate in surveys. It also includes the foundation for user profiles, interests, targeting, rewards, credit wallets, subscriptions, payments, and gamification.

## Overview

- User authentication and profile management
- Survey categories, tags, targeting, and participation
- Credit wallet and transaction tracking
- Survey reward budget management
- Subscription plans and payment records
- User progress, levels, and badges

Tài liệu API và quy tắc tra cứu danh mục: [Metadata V1](docs/metadata/README.md).

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Flyway
- Maven
